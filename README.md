A program that forecasts GTA VI's launch-day Twitch viewers for hours 2-24 as five quantiles per hour, similarity-weighting the release-day shapes of past big launches by how their first hours compare.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
